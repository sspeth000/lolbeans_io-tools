LOLBeans diagnostics bookmarklet
=================================

The external-loader bookmarklet failed, so this version is self-contained. It does NOT load a second file or contact GitHub when you run it.

Setup:
1. Copy the complete single line below, starting with javascript:
2. Create a bookmark in your browser.
3. Edit the bookmark and paste the line into its URL/address field. Save.
4. Open LOLBeans, then tap the bookmark.
5. A small report panel should appear. Use "Copy report JSON" to copy the findings.

What it checks:
- Page URL, ready state, and canvas count
- Window globals with names related to game, player, physics, Three.js, Ammo, and input
- Whether a few expected names are direct window properties (it does not invoke getters)

This is a read-only diagnostic. It does not modify movement or physics. If tapping the bookmark still does nothing, the browser may be stripping or blocking javascript: bookmarks. Try creating/editing the bookmark on desktop and then syncing it to mobile.
