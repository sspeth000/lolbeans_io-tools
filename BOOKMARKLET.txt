LOLBeans in-closure diagnostics — bookmarklet
===============================================

The repository's lolbeans.js now exposes a read-only diagnostic function from inside the game's private closure:
window.__lolbeansDiagnostics()

IMPORTANT: editing this repository does not change the live code already served by lolbeans.io. This bookmarklet only works on a page where the patched lolbeans.js bundle has actually been loaded. If it says the hook is missing, the live page is still running the site's unpatched bundle.

How to run:
1. Load the patched lolbeans.js in the environment you are testing.
2. Create/edit a browser bookmark and paste the one-line bookmarklet below into its URL/address field.
3. Open that test page and activate the bookmark.
4. Copy the JSON report and send it back here.

Bookmarklet (one line):
javascript:(()=>{try{document.getElementById('__lbdiag')?.remove();const fn=window.__lolbeansDiagnostics;if(typeof fn!=='function'){alert('LOLBeans diagnostic hook not found. The page must load the patched lolbeans.js from this repository; editing GitHub alone does not patch lolbeans.io.');return}const report=fn(),p=document.createElement('div');p.id='__lbdiag';p.style.cssText='position:fixed;z-index:2147483647;inset:10px 10px auto;background:#101820;color:#fff;border:2px solid #58c4dd;border-radius:12px;padding:12px;max-height:75vh;overflow:auto;font:13px/1.45 monospace;white-space:pre-wrap;overflow-wrap:anywhere';const h=document.createElement('div'),t=document.createElement('b');t.textContent='LOLBeans in-closure diagnostics (read-only)';const c=document.createElement('button');c.textContent='Close';c.style.cssText='float:right;padding:6px';c.onclick=()=>p.remove();h.append(t,c);const pre=document.createElement('pre');pre.style.cssText='white-space:pre-wrap;overflow-wrap:anywhere';pre.textContent=JSON.stringify(report,null,2);const b=document.createElement('button');b.textContent='Copy report JSON';b.style.cssText='padding:8px;margin-top:8px';b.onclick=async()=>{try{await navigator.clipboard.writeText(JSON.stringify(report,null,2));b.textContent='Copied!'}catch(e){const ta=document.createElement('textarea');ta.value=JSON.stringify(report,null,2);ta.style.cssText='width:100%;height:100px';p.append(ta);ta.focus();ta.select();b.textContent='Select text and copy'}};p.append(h,pre,b);(document.body||document.documentElement).append(p)}catch(e){alert('Diagnostics error: '+e)}})()

Scope:
- Reports the local player, player list, positions, velocity, input flags, ground/flying flags, scene child count, camera position, and physics object count.
- Read-only: does not change movement, inputs, or physics.
- If the hook is missing, the currently loaded game bundle was not patched.
